\section{氨的制备和性质\texorpdfstring{\quad}{ }铵离子的检验}
\subsection*{实验目的}
\begin{enumerate}[1.]
  \item 学会实验室制取氨的方法；
  \item 认识氨的物理性质和化学性质；
  \item 学会检验氨和铵离子的方法。
\end{enumerate}
\subsection*{实验用品}
试管、铁架台、酒精灯、玻璃棒、药匙、玻璃片、研钵、带导管的塞子、胶头滴管、水槽、棉花。

氯化铵、硫酸铵、硝酸铵、氢氧化钙、氢氧化钠溶液、浓盐酸、浓硫酸、浓硝酸、红色石蕊试纸、酚酞试液。
\subsection*{实验步骤}
\begin{enumerate}[1.]
  \item 氨的制取
  \begin{enumerate}[(1)]
    \item 取氯化铵和氢氧化钙各一药匙，放在研钵里，用玻璃棒充分拌和，有什么气味发生？说明发生了什么反应？写出化学方程式。
    \item 把上面的混和物放到试管里，用带导管的塞子塞住试管口，并固定在铁架台上。导管的另一头向上伸入另一个干燥的倒置的试管里（见\cref{fig:a1}）。

      \caption{氨的制取}\label{fig:a1}
    \end{figure}
    \item 用小火加热试管，便有氨气生成。
  \end{enumerate}
  \item 氨的性质
  \begin{enumerate}[(1)]
    \item 在收集氨气的试管口处，放一条润湿的红色石蕊试纸，待红色石蕊试纸变蓝时，即说明试管中的氨气已经收集满了，这时停止加热。把倒立的试管轻轻拿下，并用拇指堵住管口。注意观察氨气的颜色、气味、状态。
    \item 将上述充满氨气的试管，管口向下倒拿着放到水槽的水里去（\cref{fig:a2}）。把拇指放开。看到什么现象？为什么？

      \begin{minipage}[b]{0.48\linewidth}\centering
        \includegraphics{A-3.pdf}
        \caption{氨与酸的反应}\label{fig:a3}
      \end{minipage}
    \end{figure}
    \item 当水进入试管后，在水面下用拇指堵住试管，把试管从水里取出，管口向上，振荡试管，并向溶液里滴入几滴酚酞试液，观察有什么现象？
    \item 将实验步骤 1 里制取氨的试管按\cref{fig:a3} 装好。用玻璃棒蘸浓硫酸、浓硝酸和浓盐酸，在玻璃片上的不同地方各滴一滴（玻璃棒每取过一种酸后，要用水洗干净后，再用来取另一种酸）。然后加热氯化铵和氢氧化钙的混和物，当有氨放出时，移动玻璃片，使导管口依次对着三滴不同的酸。这时各有什么现象产生？为什么有的酸滴上冒白烟？玻璃片上生成的三种白色物质各是什么？写出三个反应的化学方程式。

\subsection*{实验用品}
试管、酒精灯、试管夹、胶头滴管、烧瓶、铁架台、导管、水槽、小木条、橡皮塞。

浓硝酸、稀硝酸（$1:2$）、浓硫酸、硝酸铜、硝酸钠、硝酸铵、铜片、石蕊试液、蓝色石蕊试纸。
\subsection*{实验步骤}
\begin{enumerate}[1.]
  \item 硝酸的性质
  \begin{enumerate}[(1)]
    \item 浓、稀硝酸对石蕊试液的作用\quad 取两个试管，分别注入浓、稀硝酸各 \qtyrange{1}{2}{ml}，再分别滴入几滴石蕊试液，微热，看到石蕊试液在稀硝酸中变红，而在浓硝酸中褪色。为什么？
    \item 浓硝酸跟铜的作用\quad 在一个试管中放入一片铜片，再滴入几滴浓硝酸，观察放出气体的颜色。
    
    向这个试管里加入 \qty{5}{ml} 水，观察溶液的颜色。

    上述现象说明有什么物质生成？写出浓硝酸跟铜反应的化学方程式。

    在烧瓶里放 \numrange{3}{4} 片铜片，再倒入稀硝酸到浸没铜片为止。把烧瓶加热，用排水取气法收集一试管一氧化氮。

      \includegraphics{A-4.pdf}
      \caption{\ce{NO} 的生成}\label{fig:a4}
    \end{figure}

    注意观察一氧化氮的颜色。

    \item 把少量固态硝酸钠、硝酸铜、硝酸铵分别放进三个试管里，各加入少量浓硫酸，再向每个试管里加入一小片铜。加热试管，观察有什么现象发生。写出有关反应的化学方程式。

\end{enumerate}
\subsection*{实验用品}

\section{胶体的性质}
\subsection*{实验目的}
了解胶体的制备方法及其性质。

\subsection*{实验用品}
烧杯、铁架台、石棉网、试管、试管夹、酒精灯、胶头滴管、量筒、厚纸筒、聚光手电筒。

饱和氯化铁溶液、$1M$ 盐酸、水玻璃、氯化钠溶液、硫酸镁溶液。
\subsection*{实验步骤}
\begin{enumerate}[1.]
  \item 胶体的制备
  \begin{enumerate}[(1)]
    \item 制取氢氧化铁溶胶\quad 用烧杯盛 \qty{30}{ml} 蒸馏水，加热到沸腾。然后逐滴加入饱和氯化铁溶液，边加边振荡，直至溶液变成红褐色，即得氢氧化铁溶胶。
    \item 制取硅酸溶胶
    
    在一个大试管里装入 \qtyrange{5}{10}{ml} 盐酸，并加入 \qty{1}{ml} 的水玻璃，然后用力振荡，即得硅酸的溶胶。
  \end{enumerate}
  \item 胶体的性质
  \begin{enumerate}[(1)]
    \item 胶体的丁达尔现象\quad 用有一小洞的厚纸圆筒（筒径比试管略大些）套在盛有氢氧化铁溶胶（或硅酸溶胶）的试管外面，让日光从小洞进入溶液（或用聚光手电筒照射小孔）。我们从圆筒上方向下观察，可以看到溶胶里有一条光亮的“通路”。用盛有食盐溶液的试管做同样的实验，有没有丁达尔现象发生？
    \item 胶体的凝聚
    \begin{enumerate}[label=\protect\cnum{\arabic*}]
      \item 在一个试管里加入 \qty{3}{ml} 氢氧化铁溶胶，再加入硫酸镁溶液振荡，观察有什么现象发生？
      \item 在一试管里加入 \qty{3}{ml} 氢氧化铁溶胶，然后再加入 \qty{3}{ml} 硅酸溶胶，振荡后，观察有什么现象发生？
      \item 在一试管中加入 \qty{3}{ml} 硅酸溶胶，用试管夹夹住，在酒精灯上加热，观察有什么现象发生？
    \end{enumerate}
  \end{enumerate}
\end{enumerate}
\begin{Theorem}{问题和讨论}
用什么方法可以鉴别一瓶液体是溶液而不是溶胶？
\end{Theorem}


\section{电解质溶液}
\subsection*{实验目的}
巩固电解质溶液的知识，练习 pH 试纸的使用。

\subsection*{实验用品}
试管、试管夹、玻璃棒、酒精灯、pH 试纸。

三种未知 pH 值的溶液、$0.1M$ 盐酸、$0.1M$ 醋酸、硫酸铵溶液、氯化钠溶液、醋酸铵溶液、碳酸钠溶液、醋酸钠溶液、饱和的硫酸铝溶液和碳酸氢钠溶液、酚酞试液、锌粒。

\subsection*{实验步骤}
\begin{enumerate}[1.]
  \item pH 试纸的使用
  
  用干净的玻璃棒沾取少量未知液，滴在一小块 pH 试纸上，观察试纸的颜色变化并跟标准比色卡相比，分别确定三种未知溶液的 pH 值。注意每取过一种未知液后，要用水把玻璃棒冲洗干净，再用来取另一种未知液。比较哪种溶液的氢离子浓度最大。
  \item 强弱电解质
  
  在两个试管里分别 加入 \qty{2}{ml} $0.1M$ 盐酸和 $0.1M$ 醋酸，用玻璃棒沾取少量溶液滴在一小块 pH 试纸上，测定它们的 pH 值。然后分别加入一小粒锌，并加热试管，比较两个试管里反应的快慢。写出反应的离子方程式。
  \item 盐类的水解
  \begin{enumerate}[(2)]
    \item 在四个试管里分别加入 \qty{1}{ml} 碳酸钠、硫酸铵、氯化钠、醋酸铵溶液、用 pH 试纸测定它们的 pH 值。由此可以得出盐类水解的简单规律是什么。写出水解反应的离子方程式。
    \item 在试管里加入 \qty{3}{ml} 醋酸钠溶液，滴入几滴酚酞试剂，观察溶液的颜色。把上述溶液的一半倒入另一个试管里，在酒精灯上加热，比较两个试管里溶液的颜色，并思考温度对水解有什么影响。
    \item 泡沫灭火器的反应原理
    
    在两支试管里分别加入 \qty{2}{ml} 饱和硫酸铝和碳酸氢钠溶液，然后把一个试管里的液体倒入另一个试管里，观察发生的现象。写出反应的离子方程式。
  \end{enumerate}
\end{enumerate}
\begin{Theorem}{问题和讨论}
\begin{enumerate}[1.]
  \item 有人说氯化钠溶液和醋酸铵溶液的 pH 值都接近 7，因此它们都没有发生水解。这种说法对不对？说明理由。
  \item 有下列浓度相同的溶液，把它们按 pH 值由小到大的顺序排列起来。
  \[\ce{Na2S},\quad\ce{CH3COONH4},\quad\ce{HCl},\quad\ce{NaOH},\quad\ce{Al2(SO4)3}\]
\end{enumerate}
\end{Theorem}

    \item[T] $273 + 100 = \qty{373}{K}$
    \item[R] \qty{0.082}{L.atm.K^{-1}.mol^{-1}}
    \item[n] $n=\dfrac{W_2-W_1}{\mathrm{M}}$（$\mathrm{M}$：四氯化碳的摩尔质量）
  \end{EqDesc}
  \begin{align*}
    \mathrm{M} & =\frac{RT(W_2-W_1)}{PV} \\
     & =\frac{0.082\times 373(W_2-W_1)}{V}
  \end{align*}
  摩尔质量的数值与分子量是相同的。
\end{enumerate}

\end{Theorem}

    \task \ce{K2CO3}，
    \task \ce{NH4Cl}，
    \task \ce{CH2COONH4}。
  \end{tasks}
  \item 在试管里放入少量明矾，加水溶解，试验它的酸碱性. 判断它是不是胶体。

  \item 只用一种试剂，鉴别下列物质的溶液。
  \[\ce{NaCl},\quad\ce{MgCl2},\quad\ce{Al2(SO4)3},\quad\ce{NH4Cl}\]
  \item 用已知浓度的盐酸滴定未知浓度的氢氧化钾溶液，测定它的浓度。
